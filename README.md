Sunset Bay — an open-world crime game: drive and run through a low-poly sun-soaked coastal city at sunset, steal cars, run jobs for cash, and outrun the police as your wanted stars rise.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step and no network — the game is plain static files (a raw-WebGL renderer written for this game, no library), played with keyboard and mouse: WASD to move and drive, mouse drag to orbit the camera, E to enter or exit a car, Shift to run, Space for the handbrake, R to restart, P to pause, M to mute. Progress (best cash, jobs done, cars stolen) saves in your browser — Continue on the title screen resumes your last run.
